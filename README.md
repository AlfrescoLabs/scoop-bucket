# scoop-bucket

Scoop bucket of AlfrescoLabs. These tools are not official Hyland products, and Hyland does not officially support them.

| Manifest | What it is |
| --- | --- |
| `openarch` | [CLI for OpenArch](https://github.com/AlfrescoLabs/openarch-cli) |
| `openarch-app` | [openarch-app](https://github.com/AlfrescoLabs/openarch-app), the plugin of the CLI for OpenArch that runs App for OpenArch. It also installs `openarch` |

```powershell
scoop bucket add alfrescolabs https://github.com/AlfrescoLabs/scoop-bucket
scoop install openarch
scoop install openarch-app
```
